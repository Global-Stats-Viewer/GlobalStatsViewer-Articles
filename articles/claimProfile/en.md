# How to Claim a Profile {id=how-to-claim-profile}
### If you are the person behind a profile on the leaderboard, here's how you can claim it.
## Claiming an account {id=claiming-account}
To claim an unregistered user, use the normal login system to initiate a claim.

For AREDL and Pemonlist, this works assuming your account has been created with the same Discord account you're using to login.

The Pointercrate Demonlist requires a different process, with a guide provided on our account linking guide.

As for Geometry Dash / Updated Leaderboard, it works if on the Updated Leaderboard, you are linked to said Geometry Dash account using the same Discord account.
