# GSV Articles
Welcome to Global Stats Viewer articles repository. If your goal is to translate text that is not an article, then check out the [translations repo](https://github.com/Global-Stats-Viewer/GlobalStatsViewer-translations). This repo consists of all articles found on the [GSV support page](https://globalstatsviewer.com/support) along with version changelogs.
- keep `#` as the title
- Every "change" should be preceded by `-`
  - By this, it is meant as every bullet point in a changelog
- No Discord mentions
- Do NOT use these symbols `µ £`
## Language Code Guide
Inside each article folder, the markdown file should be titled by the [ISO 639 language code](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes#Table). For example, English is known as `en`. For a national version of an existing language, use the code followed by `-` and then the [ISO 3166 country code](https://en.wikipedia.org/wiki/List_of_ISO_3166_country_codes#Current_ISO_3166_country_codes). For example, if someone added Brazilian Portuguese, it would be `pt-br`. All codes are in lowercase.
